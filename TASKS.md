Generated by `tools/catalog.mjs` (`build` / `render` / `check`) from the gate plus `tools/catalog-content.json`, which holds one original one-line description and one family per id and the seven licence-clean ids withheld with the reason. `npm run validate:catalog` fails when data, HTML and the repository doc disagree, when a refused or omitted id appears on the page, or when a card is not credited; `tools/build-site.sh` runs render + check before every deploy. Policy sections (how it works, licence gate, excluded, submit, credits/attribution) sit below the grid; no publisher artwork is used — cards get a deterministic two-letter monogram in a Cybercore token tint.
- [x] Run `catalog:scan` as a CI gate so a newly pending licence fails a build instead of a release.
- [x] Build the tmLanguage → Monarch converter (`tools/tm2monarch.mjs`, `npm run grammar:test`): inlines `repository` includes with cycle detection, maps TextMate scopes onto Monarch tokens, turns `begin`/`end` pairs into states and `captures` into token arrays, converts Oniguruma anchors, and reports every construct Monarch cannot express instead of approximating it. Its 16-case self-test feeds each output through Monaco's own `monarchCompile.js`; verified on real grammars (Red Hat YAML → 40 states, VS Code Markdown → `while` reported and dropped). This is what makes the grammar rows in `FOSS_EXTENSION_REPOSITORY.md` reachable as Tier A — the remaining half is extending `validate-packs.mjs` to check a converted grammar inside a pack.

Add `packaging/aur/make-bin-tarball.sh` (byte-reproducible repack of an Arch package: sorted entries, fixed mtime/owner, `gzip -n` — verified identical sha256 across runs) and `tools/aur-release.sh`, which verifies the GitHub tag, recomputes both `sha256sums` from the real artifacts, bumps `pkgver`/`pkgrel`, regenerates both `.SRCINFO`, and pushes to `ssh://aur@aur.archlinux.org/<pkg>.git`. The script refuses to publish while any checksum is `SKIP`. Documented in `packaging/aur/README.md`, `README.md`, and `docs/install-arch.md`.

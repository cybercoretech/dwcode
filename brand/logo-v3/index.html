// Bracket, set in real coding fonts

The Bracket identity kept intact: drawn chamfered brackets frame the name, cyan D, magenta W, steel CODE, and the block cursor. The letters are now a FOSS coding font at its heaviest weight, so the type is editable. All six fonts use the SIL Open Font License 1.1. Motion: anime.js 4.5.0.

After you pick, the chosen font is self-hosted with its licence, and the logo is exported both as editable SVG (live text) and as outlined paths for icons.
